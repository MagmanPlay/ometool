**OMETOOL** — это интерактивный bash-скрипт для быстрой, безопасной и удобной настройки чистых серверов на базе **Ubuntu 24.04**. 

Инструмент избавляет от рутины при деплое новых VPS/VDS, автоматизируя базовую защиту, оптимизацию сети и установку необходимого софта через удобное консольное меню.

---

## ⚡ Быстрый запуск

Вам не нужно клонировать репозиторий или скачивать файлы вручную. Просто подключитесь к вашему серверу и выполните одну команду от имени `root`:

```bash
bash <(curl -sSL https://raw.githubusercontent.com/MagmanPlay/ometool/main/ometool.sh)
```

🛠️ Доступные модули
При запуске скрипта откроется интерактивное меню, где вы можете выбрать нужный модуль. Каждый скрипт скачивается в оперативную память и выполняется "на лету", не оставляя мусора на сервере.

[1] 🏗️ Базовая подготовка (System Prep)
Идеально для первого запуска на свежем сервере. Включает в себя:
Обновление системы (apt update & upgrade).
Настройка безопасности (UFW): Закрытие всех портов, кроме 22 (SSH) и 443 (HTTPS), установка fail2ban.
Приватность (DNS-over-TLS): Перевод сервера на зашифрованные DNS от Cloudflare и Google через systemd-resolved.
Оптимизация сети (TCP BBR): Включение алгоритма BBR для максимальной пропускной способности и снижения задержек.
Автоматизация (Cron): Настройка автоматического обновления и перезагрузки сервера каждые 15 дней в 03:00 ночи.
Очистка: Отключение лишних облачных сервисов (cloud-init, rpcbind и др.).

[2] 🐳 Установка Docker & Compose
Надежный метод установки Docker для Ubuntu 24.04.
Полная очистка от старых или конфликтующих пакетов docker-ce.
Установка стабильных docker.io и docker-compose-v2 из официальных репозиториев Ubuntu.
Добавление демона в автозагрузку и проверка работоспособности.

[3] 🌐 Деплой DNSTT Tunnel
Интерактивный мастер для развертывания DNS-туннеля (DNSTT + BadVPN UDPGW).
Запрашивает ваш домен и желаемое имя пользователя.
Автоматически освобождает 53 порт.
Компилирует и настраивает dnstt-server и badvpn-udpgw (порт 7300).
Генерирует ключи шифрования, создает изолированного SSH-пользователя без доступа к shell (nologin).
Заворачивает всё в надежные systemd сервисы.

[4] 🧹 Очистка системы (Smart System Cleaner)
Двухуровневая интерактивная утилита для поддержания сервера в чистоте. Скрипт анализирует дисковое пространство и наглядно показывает, сколько мегабайт было освобождено по итогу. 

Включает два режима работы:
* **🌱 Легкая очистка (Safe Mode):** Идеально для регулярной профилактики. В один клик и абсолютно безопасно удаляет кэш `apt`, старые зависимости, временные файлы пользователя и ротирует системные журналы (оставляя логи только за последние 7 дней).
* **🔥 Жесткая очистка (Interactive Mode):** Мощный инструмент для ситуаций, когда диск забит на 100%. Скрипт находит "жрунов" места и запрашивает ваше подтверждение перед каждым действием. Умеет:
  * Агрессивно сжимать журналы `systemd` (до 10MB).
  * Находить и удалять старые архивированные логи (`*.gz`, `*.1`) и отчеты о крашах.
  * Обнулять (truncate) огромные текущие логи (`syslog`, `messages`) без удаления самих файлов и остановки сервисов.
  * Интеллектуально распознавать наличие Docker и предлагать глубокую зачистку (удаление остановленных контейнеров, висячих образов и неиспользуемых сетей).

[5] 🐍 Деплой Python-бота (Авто venv + systemd)
Ультимативный скрипт для быстрого запуска Python-скриптов в фоновом режиме. Идеально подходит для Telegram-ботов и парсеров.
* Спрашивает имя сервиса и абсолютный путь к вашему `.py` файлу.
* Автоматически создает изолированное виртуальное окружение (`venv`) прямо в папке со скриптом.
* Интеллектуально находит файл `requirements.txt` и устанавливает все нужные библиотеки через `pip`.
* Генерирует надежный `systemd` юнит с авторестартом при падениях (`Restart=always`).
* Запускает бота и выдает список удобных команд для чтения логов.

📋 Требования
ОС: Ubuntu 24.04 LTS (Noble Numbat). На других версиях работоспособность не гарантируется.

Права: root или пользователь с правами sudo.

Утилиты: curl (обычно предустановлен).
